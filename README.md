Selected source code, templates, guides and starter kits are available through the shop. This repository contains the portfolio website and project previews; individual application codebases are maintained separately.

## Run locally

```bash
npm ci
npm run dev
```

Build for production with `npm run build`; preview the result with `npm run preview`. Netlify builds the site with `npm run build` and publishes `dist/`.

## Update content

- `src/data/site.ts`: project descriptions, links, technologies, shop listings and profile content.
- `src/assets/thumbnails/`: optimized project screenshots and artwork.
- `docs/project-audit.md`: project inventory, evidence and exclusions.

Portfolio screenshots do not require access to private workspaces. Personal files, credentials, signing keys, databases and backups are excluded from project publishing.
